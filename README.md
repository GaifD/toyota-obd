# Бортовик

Android-приложение для OBD2 через Bluetooth-адаптер ELM327: бортовой компьютер (расход, поездки, запас хода),
спидометр в км/ч с HUD-режимом, ошибки с расшифровкой на русском, диагностика катализатора (Mode 6, датчики кислорода,
пропуски, коррекции). Работает на любой машине с OBD2; для гибридов Toyota есть дополнительные данные.

APK собирается в GitHub Actions и выкладывается в Releases — приложение само предлагает обновление.
